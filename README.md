## 📋 Overview

This repository serves as a showcase of my Python development journey, containing both fundamental learning exercises and practical automation projects. The focus is on building robust Python applications while integrating Infrastructure as Code (IaC) practices using Terraform for cloud resource management.

### Key Features

- ✅ **Python Learning Projects** - Foundational to intermediate programming exercises
- ✅ **Automation Scripts** - Practical solutions for system utilities and cloud operations
- ✅ **Infrastructure as Code** - Terraform integration for AWS resource provisioning
- ✅ **Cloud Integration** - AWS S3 backup automation with Python
- ✅ **Clean Code Practices** - Well-structured and documented scripts

## 🚀 Projects

### 🔹 Infrastructure Automation (`project_01/`)
A comprehensive Infrastructure as Code (IaC) implementation using Terraform:
- Automated cloud resource provisioning
- Modular infrastructure architecture
- Integration with AWS services
- Continuous deployment workflows

### 🔹 AWS S3 Backup Automation (`backup_with_s3.py`)
Python script for automated backups to Amazon S3:
- Secure file upload to S3 buckets
- Automated backup scheduling
- Error handling and logging
- Configurable backup parameters

### 🔹 Calculator Application (`calculator.py`)
A feature-rich calculator demonstrating Python fundamentals:
